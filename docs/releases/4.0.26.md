## AgriCraft Re-Reloaded 1.21.1-4.0.26

### Added

- New option `compat.create_harvester_reverts_growth` (default `true`, NeoForge with Create). When a Create Mechanical Harvester passes over an AgriCraft crop that is not mature yet, the crop and its weeds go back one growth stage, as in earlier versions. Set it to `false` to leave unripe crops untouched. Mature crops are harvested either way and return to their post-harvest stage.

### Fixed

- Create harvesters no longer stall in front of crops on crop sticks while `core.crop_sticks_collide` is enabled. Harvesters now move through AgriCraft crop blocks, including empty and cross sticks, without breaking them. Players and mobs still collide with the sticks.

### Downloads

- `AgriCraft-neoforge-1.21.1-4.0.26.jar`: Minecraft 1.21.1 with NeoForge.
- `AgriCraft-fabric-1.21.1-4.0.26.jar`: Minecraft 1.21.1 with Fabric. The Create integration is NeoForge-only; this build only carries the new config entry.

### Validation

Both production builds and archive checks passed. The NeoForge release jar ran a real Create 6.0.10 piston harvester over wheat on bare farmland and on crop sticks with both option values, and the rig was also tested by hand in a NeoForge client. See [release verification](https://github.com/Vivoxti/AgriCraft-ReReloaded/blob/4.0.26/docs/releases/4.0.26-VALIDATION.md) for details and limits.
