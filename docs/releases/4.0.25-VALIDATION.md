Verified on November 7, 2026, using Java 21.0.10, Minecraft 1.21.1 and NeoForge 21.1.226.

## Animal food

AgriCraft seeds share one item, so vanilla checks such as `stack.is(ItemTags.CHICKEN_FOOD)` never matched them. A disassembly of all 941 Minecraft 1.21.1 entity classes showed that animals check food only through item tags; seed items are compared directly only by villager behaviors, trades and professions. The fix therefore applies to item tags whose path ends in `_food` or `_tempt_items` and leaves every other tag untouched.

The probe ran on a NeoForge development server with a survival fake player feeding real entities through `Player.interactOn`. Chickens enter love mode with all five seed types and consume exactly one seed; a sniffer, pigs and a rabbit do the same with their seeds; a parrot was tamed; a cow ignores wheat seeds. Tag checks also confirm the negative cases: wrong animals, villager planting tags and AgriCraft flower seeds.

## Seed bag

Since the 1.20.5 port, every seed bag method edited a copy of the item's custom data and discarded it, so inserted seeds were removed from the player but never stored. The probe drives real inventory clicks through `AbstractContainerMenu.clicked` and checks both insert paths, species rejection, merging, save/load, capacity leftovers, planting through `ServerPlayerGameMode.useItemOn`, full extraction and reuse.

The sorter probe found that the sorter list was only filled when the lazy stat registry was first used; before that, switching had nothing to switch to. Sorters are now registered when the seed bag class loads. The probe covers the payload codec, direction mapping, wrap-around in both directions, unchanged contents and non-bag items.

## Commands

`/agricraft_seed` passed a `ResourceLocation` as a chat translation argument. Such arguments cannot be serialized, so the `system_chat` packet failed and the player was disconnected after receiving the seed. The probe runs all three command forms and encodes each reply with `ClientboundSystemChatPacket.STREAM_CODEC`.

## Manual checks

Before the version bump, a NeoForge development client was used to check by hand that the seed bag stores, merges and releases seeds of one species with different stats, and that sneak + scroll changes the sorter. Animal feeding was covered only by the probe.

## Limits

All probes and manual checks ran in the NeoForge development environment on the release source before the version bump, not against the final versioned JAR on a separate server. Client input routing for sorter scrolling has no automated coverage. Fabric passed build, archive and remapping checks and a development client started with the new mixins applied; no Fabric gameplay session was run. Other compatibility suites were not rerun for this patch.
