# Release 4.0.28 verification

Verified on November 15, 2026, using Java 21.0.10, Minecraft 1.21.1, NeoForge 21.1.226, Create 6.0.10, Create: Integrated Farming 1.3.2 and Create Dragons Plus 1.11.7b.

| Check | Result | Evidence |
| --- | --- | --- |
| NeoForge and Fabric production builds | Both succeeded after cleaning the `common`, `neoforge` and `fabric` projects | `./gradlew :common:clean :neoforge:clean :fabric:clean :neoforge:build :fabric:build` |
| Development content isolation | All main, source and dev-shadow archives passed | `tests/starfield/verify_release.py` |
| Release contents and metadata | Loader metadata reports `4.0.28`; `agricraft-cif.mixins.json` is listed in `neoforge.mods.toml` and its mixin and plugin classes are present in the NeoForge archive | Archive listing |
| Vacuum Harvester, 4.0.27 | AgriCraft crops at every stage unchanged; vanilla wheat at age 7 harvested | Client run, see below |
| Vacuum Harvester, 4.0.28 | Mature AgriCraft wheat with and without crop sticks went from stage 7 to the post-harvest stage 4; stages 0 to 6, the sticks and vanilla wheat below age 7 unchanged; harvester inventory held the AgriCraft wheat and seeds plus the vanilla drop; the mixin applied without errors | Client run, see below |
| Empty product tag, 4.0.27 | Crash report: `IllegalArgumentException: Bound must be positive` in `AgriPlant.getHarvestProducts` | Client run, see below |
| Empty product tag, 4.0.28 | No crash; mature Cuprosia went from stage 7 to 4 without drops; one warning naming `agricraft:nuggets/copper` was logged | Client run, see below |
| Create Mechanical Harvester regression | Same stages as 4.0.26 with `compat.create_harvester_reverts_growth` set to `true` and `false`; the contraption kept moving | Client run |

## Client run

An automated NeoForge client loaded a test world with a stationary Vacuum Harvester powered by a creative motor at 256 RPM. Under it were three rows of crops at stages 0 to 7: AgriCraft wheat on farmland, AgriCraft wheat on wooden crop sticks and vanilla wheat as a control. After one harvest pulse the stages, block states and harvester inventory were read with commands. For the empty-tag scenario, a datapack replaced `#agricraft:nuggets/copper` with an empty tag and the AgriCraft rows held Cuprosia.

## Limits

The contraption-mounted Vacuum Harvester was not tested in game; it calls the same harvest function as the placed block. Clipping and raking with an empty product tag were not tested in game; they use the same product helper as harvesting. The compatibility is NeoForge only, like Create: Integrated Farming itself. The empty-tag fix was built for Fabric but only run on NeoForge.
