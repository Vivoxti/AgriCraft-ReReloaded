Data generation completed all providers and wrote no changed resources. Its Java main method returned, but idle non-daemon worker threads prevented process exit. The completed data-generator process was stopped, and the production build was run separately to successful completion. The archive audit independently compared all generated files with the packaged resources.

## Clipping

The final NeoForge production JAR ran on a disposable dedicated server with NeoForge 21.1.226, Resourceful Config 3.0.11, Mystical Agriculture 8.0.27 and Cucumber 8.0.16. A survival fake player uses the normal `ServerPlayerGameMode.useItemOn` path against actual crop block entities and registered plant definitions.

Wheat, Ferranium, Inferium, Iron and Diamond are tested at immature and mature stages. Rejected clipping must preserve growth and genome, spawn no items and send exactly the appropriate translation key. Immature Allium is also rejected with the maturity message. Sixty-four mature Allium trials verify that configured flower clipping still resets growth on both successful and unsuccessful drop rolls; the final run produced items in 17 trials and none in 47. A random drop roll yielding nothing remains distinct from a plant without clipping products.

Local evidence: `build/release-4.0.24/clipping/server/clipping-results.txt` and its server log.

## Cloning

The final NeoForge JAR ran on two disposable dedicated servers, first with the new configuration entry absent and then explicitly enabled. The regression probe uses the production parent selector and cloning/combining engine with synthetic crop objects and a registered wheat genome. It checks default refusal, enabled cloning, unchanged two-parent breeding, explicit datapack permission, maturity, Fertility selection, spread chance, namespace isolation, the compatibility switch and turning the option back off.

Local evidence: `build/release-4.0.24/cloning/default/mystical-cloning-results.txt` and `build/release-4.0.24/cloning/enabled/mystical-cloning-results.txt`.

Earlier graphical-client checks used the local build before the release version bump, with actual Mystical Agriculture seeds planted through item use. Inferium, Iron and Diamond were tested with one and two mature parents, three repetitions each, and the option both disabled and enabled: 36 breeding scenarios. Maturity was prepared by the test fixture and ordinary crop growth ticks were invoked repeatedly; Fertility, spread chance and plant data were unchanged. Weeds and random world ticks were disabled to isolate breeding. This was not a natural-growth timing measurement. The packaged Mystical Agriculture definitions retain `cloneable=false`; the option overrides cloning at runtime.

## Limits

Fabric passed build and archive checks; no Fabric gameplay session was run. The final versioned JAR was not rerun in a new graphical-client session; final clipping and cloning checks ran on dedicated servers. Other compatibility suites were not rerun for this patch.

A separate earlier graphical-client check observed clippers in the offhand failing to trigger with an empty main hand. This release does not change hand routing or claim to fix that observation. The clipping fix prevents unsupported clipping from resetting growth when the item action is reached.
