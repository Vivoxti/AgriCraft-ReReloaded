## Client run

A NeoForge client loaded a test world with AgriCraft 4.0.29, Resourceful Config and the separate test mod `tests/clipping/ClipperGainProbe.java`. On server start the probe planted a mature poppy on crop sticks with the given Gain, clipped it with a survival fake player through `ServerPlayerGameMode.useItemOn`, counted the dropped items and repeated this 400 times per case. With 400 clips the expected spread is about ±2.5 percentage points per standard deviation; the probe accepts ±8 points around 25%, 50% and 75%, and requires exactly 100% at Gain 10.

## Limits

Only vanilla flower clipping data (chance 0.5, amount 0 to 1) was measured. Plants whose clipping products already have a higher chance or a minimum above zero follow the same formula from their own base chance. The Fabric build uses the same common code but was not run in game.
