## AgriCraft Re-Reloaded 1.21.1-4.0.30

### Added

- Crop sticks can be submerged in fluids from other mods, not only water and lava. This lets a modpack make a magical crop that grows only in, say, quicksilver.
  - List the fluid ids in the new `core.fluidloggable_fluids` option, for example `["somemod:quicksilver"]`. The list is empty by default, and then the crop block is unchanged.
  - Pour a bucket of that fluid into the crop sticks, and require it in the plant's `fluid_condition`.
  - The list is read at game start, so changes need a restart. The server and every client must use the same list: a client with a different list is disconnected with a message naming both lists.
  - Each listed fluid adds 816 crop block states, so keep the list short. Removing a fluid from the list later leaves crops that held it dry.

### Fixed

- JEI's recipe transfer (the **+** button) now uses AgriCraft seeds for recipes that take any seed, such as the Journal or other mods' recipes with `#c:seeds`. Before, JEI reported the seed as missing even with AgriCraft seeds in the inventory. Looking up a seed's recipes in JEI still shows only that plant's recipes.
- A plant that requires a fluid no longer counts as fertile while standing in lava; it burns, as in the original AgriCraft.
- A bucket poured into crop sticks that already hold a fluid is no longer emptied into nothing; it pours next to them. A bucket of a fluid the crop sticks can't hold also pours next to them instead of breaking them.
- A Create open-ended pipe drains crop sticks submerged in lava (or an extra fluid) instead of pulling from them endlessly.

### Downloads

- `AgriCraft-neoforge-1.21.1-4.0.30.jar`: Minecraft 1.21.1 with NeoForge.
- `AgriCraft-fabric-1.21.1-4.0.30.jar`: Minecraft 1.21.1 with Fabric.

### Validation

Both production builds and archive checks passed. In NeoForge clients, automated probes submerged crop sticks in a test mod's fluid, grew a datapack plant that needs it, drained it with a Create pipe and checked restarts and mismatched server lists; another probe filled the Journal recipe through JEI's **+** button from AgriCraft seeds alone. See [release verification](https://github.com/Vivoxti/AgriCraft-ReReloaded/blob/4.0.30/docs/releases/4.0.30-VALIDATION.md) for details and limits.
