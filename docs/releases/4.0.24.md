## AgriCraft Re-Reloaded 1.21.1-4.0.24

### Added

- Added `compat.mysticalagriculture_cloning` in `config/agricraft.jsonc` to allow Mystical Agriculture crops to spread from a single mature parent.
- The option defaults to `false`, preserving the original restriction. Set it to `true` in the server or single-player configuration while keeping `compat.mysticalagriculture` enabled. Normal maturity, Fertility selection and spread chance still apply.
- Two mature parents of the same species can continue to breed with the new option disabled. Offspring require empty double crop sticks adjacent to the parents.

### Fixed

- Clippers no longer reset a mature plant's growth when no clipping products are defined. They now refuse the action with **“There is nothing worth clipping here.”** and preserve the plant's growth.
- Immature plants now display **“This plant is not mature enough to clip yet.”** instead of the generic clipping message. Their growth is preserved.
- The clipping protection applies to all crops, including Mystical Agriculture and AgriCraft resource crops. Existing flower clipping products and drop chances are retained.

### Translations

- Added English, Russian, Ukrainian and Simplified Chinese text for the cloning option and immature-plant message.

### Downloads

- `AgriCraft-neoforge-1.21.1-4.0.24.jar` — Minecraft 1.21.1 with NeoForge.
- `AgriCraft-fabric-1.21.1-4.0.24.jar` — Minecraft 1.21.1 with Fabric.

### Validation

Both production builds and archive checks passed. The final NeoForge JAR passed clipping and cloning regression checks on dedicated servers. Earlier client checks covered Inferium, Iron and Diamond breeding with the option both disabled and enabled. Fabric passed build and archive validation; no Fabric gameplay session was run.
