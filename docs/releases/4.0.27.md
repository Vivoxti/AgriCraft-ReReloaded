## AgriCraft Re-Reloaded 1.21.1-4.0.27

### Added

- New option `core.load_default_plants` (default `true`). Set it to `false` to stop AgriCraft from loading its built-in plants and mutations: the vanilla crops and AgriCraft's own resource crops. This lets modpacks ship a fully custom crop set from a datapack without overriding every built-in file.
  - Soils, weeds and fertilizers still load, so custom plants keep working.
  - The mod compatibility packs are unaffected and stay controlled by `core.register_packs_by_default`.
  - Datapack files still load, including ones that reuse a built-in id such as `minecraft:wheat`.
  - Compatibility mutations whose parents were built-in plants stay inactive instead of erroring.
  - The option is read when a world loads.

### Downloads

- `AgriCraft-neoforge-1.21.1-4.0.27.jar`: Minecraft 1.21.1 with NeoForge.
- `AgriCraft-fabric-1.21.1-4.0.27.jar`: Minecraft 1.21.1 with Fabric.

### Validation

Both production builds and archive checks passed. Development servers on NeoForge and Fabric were started with the option off and a test datapack that overrides `minecraft:wheat`. On both, only the datapack's wheat was loaded, along with no mutations and all 10 soils. With the option on, NeoForge loaded every built-in plant and mutation as before. See [release verification](https://github.com/Vivoxti/AgriCraft-ReReloaded/blob/4.0.27/docs/releases/4.0.27-VALIDATION.md) for details and limits.
